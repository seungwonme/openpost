### Added

- Send ordered follow-up messages from a workflow after someone responds, either to an incoming Instagram message or to a comment campaign's private reply. Each message rechecks the 24 hour window, opt-out and takeover, and a stop or failure ends the sequence with a visible reason.
- Run one automated sequence per conversation across workflows. A later trigger finishes normally and shows why it sent nothing, and every message in a sequence counts toward the hourly and daily limits.
- Runs waiting for a person's response no longer count toward the workspace's active run limit.
- End a sequence's approval when its messaging window can no longer be met, so it stops blocking that person's next message.
